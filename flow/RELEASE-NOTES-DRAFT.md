# Release Notes 草案（v0.8.0）

> 用途：GitHub Release 正文。完整变更见 [CHANGELOG.md](../CHANGELOG.md)（未发布段有 150+ 条）。
> 这里只挑用户能直接感知的部分，10 条左右就够。发版前按实际情况微调措辞与条目。

## 亮点

**小窗不再卡死**
绑定的窗口被关掉后会自动解绑（约 0.5 秒，状态变 `no-window` 而不是红色报错）；
同一应用重新开了窗口会自动重新绑定（约 1 秒）。两条路径都做过实机验证。

**会话隔离真正生效**
小窗只在你召唤它的那个会话里出现；切换会话时 14 毫秒内隐藏。
名字相近的会话（如「项目」和「项目详情」）不会互相误点亮。

**不再抢你的前台**
启动应用用 `-g -j` 隐藏方式，测试窗口不会丢到你桌面上；
被系统顶前台时自动还原，并在报告里如实标出「读取会抢前台」的应用（Telegram 等）。
看门狗判定「是不是你在切」改用键鼠空闲时间——你刚动过鼠标，它立刻让路。

**不碰你的数据**
- 笔记清理默认只报告；真删要 `--force`，且默认只删带 `[AGENT-TEST]` 标记的笔记
- 写文本编辑前先确认是「未命名空文稿」，有内容就跳过，不覆盖
- 填表会先把原值恢复回去，中途出错也会补一次恢复
- 清理脚本只关自己拉起的应用；你在用电脑时不会去动后台服务

**控制面有了真边界**
daemon 与 overlay 的接口都要本机 token（`~/.desktop-agent/api-token`，600 权限；daemon 的 `GET /` 存活探测除外，只回 pid/uptime）；
拒绝浏览器来源与伪造 Host（挡 DNS rebinding）；CDP 端口会校验主人，拿不到就拒绝连接。

## 修复

- 会话泄漏：任务用完不关小窗会话，攒到上限后新会话 409 → 现在用完即关、到上限先回收闲置会话
- 验收假绿：日志里同时有真实失败项与环境跳过时，现在整轮判真失败
- 锁屏时四个依赖 AX 的任务会误报失败 → 现在标「环境跳过」并退出 0
- 应用锁可被抢：加了 pid 存活检查与心跳
- 部署漂移：`npm run service:status` 现在能看出端口是不是被不受管进程占着

## 已知限制

- **只支持 macOS**（Windows 分支照 Win32 API 写好但未实机验证）
- Telegram 和部分 Electron 应用在被读取时会被系统短暂顶到前台（会自动还原）
- 锁屏时 AX 与抓图整体不可用，任务会标「环境跳过」而不是假装成功
- 少数自绘界面应用读不到界面树，只能回显画面（报告里会写明原因）

## 升级提示

- 从 0.7.0 升级：`npm run service:restart` 让新代码生效即可（服务路径没变，不用卸载重装）；`npm run service:status` 会报「代码新鲜度」，落后就提示重启
- 数据目录权限会自动收紧到 700（`hardenDataDir`），不需要手动处理
